# 🎨 木工專案視覺與 UI/UX 規範 (Visual Style & UI Rules)

在開發前端 `vuetify-project` 元件時，必須嚴格遵守以下視覺與 UI/UX 規範：

## 1. 色彩調性 (Color Palette Tokens)
- **Primary (主色)**：溫暖木褐 (`#8B4513` / `#A0522D`) - 用於 Navbar、主要 CTA 按鈕、頁尾。
- **Secondary (輔助色)**：大地米白 (`#FDFBF7`) - 用於全站背景與對話框背景，提升閱讀舒適度。
- **Accent (點綴色)**：黃銅金 (`#D4AF37`) - 用於「購買」按鈕、VIP / 認證職人標章、1-5 星評分。
- **Neutral (中性色)**：深焦炭灰 (`#2B2B2B`) - 用於內文與圖示，避免純黑帶來的冰冷感。
- **Border/Divider**：淺木紋柔邊 (`#E8E2D8`) - 用於卡片邊框與分隔線。

## 2. 畫廊與圖片放大體驗 (Gallery & Lightbox)
- **圖文佈局**：
  - 主要正面圖 $\times 1$（佔據顯眼版面，4:3 或 1:1 高解析展現全貌）。
  - 縮小版細節圖 $\times$ 最多 3 張（散落排列於正面圖側邊，帶有工藝質感）。
- **Lightbox 互動**：
  - 點擊圖片跳出高解析度放大鏡 (Zoom Lens)，滑鼠懸停時自動放大呈現木頭紋理與打磨工藝細節。

## 3. 下單防呆機制 (Mandatory Confirmation Dialog)
- 點擊下單時，必須觸發 `v-dialog` 二次確認對話框。
- 對話框必須包含：作品名稱、總金額、購買數量、木工特殊運送備註（如大型運送警示）。
- 必須阻斷 HTTP POST 請求，直到使用者於對話框中點擊「確認付款 / 下單」按鈕。

## 4. 字型與元件風格
- 標題選用 **Noto Serif TC (明體)** 呈現匠人人文質感。
- 內文與選單選用 **Noto Sans TC (黑體)**。
- 預設圓角值為 `8px`，標籤為膠囊型 `16px`。
